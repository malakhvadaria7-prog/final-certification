## Описание программы

Book Tracker — это GUI-приложение на Python для управления списком прочитанных книг.

Программа позволяет:

- Добавлять книги
- Просматривать список книг
- Фильтровать книги:
  - по жанру
  - по количеству страниц
- Сохранять данные в JSON
- Загружать данные из JSON

---

## Используемые технологии

- Python 3
- Tkinter
- JSON

---

## Инструкция по запуску

1. Установить Python 3.
2. Скачать проект.
3. Открыть папку проекта.
4. Запустить файл:

```bash
python main.py
```

---

## Проверка корректности данных

Программа проверяет:

- Пустые поля
- Корректность количества страниц

Если данные введены неверно — выводится сообщение об ошибке.

---

## Примеры использования

### Пример 1

Название: Гарри Поттер  
Автор: Джоан Роулинг  
Жанр: Фэнтези  
Страниц: 450

Результат:
Книга успешно добавляется в таблицу.

---

### Пример 2

Фильтр по жанру:
Фэнтези

Результат:
Показываются только книги жанра "Фэнтези".

---

### Пример 3

Фильтр по страницам:
200

Результат:
Показываются книги, у которых больше 200 страниц.
